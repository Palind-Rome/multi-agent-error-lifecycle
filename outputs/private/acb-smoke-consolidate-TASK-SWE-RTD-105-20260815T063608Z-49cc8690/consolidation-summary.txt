## 🔒 **Critical Constraints & User Preferences**

- **Non-Negotiable**: Use of **SHA-256 only** — no MD5, SHA-1, or generic "hashing".
- **No Raw PII Storage**: Not in queues, logs, memory, or database.
- **Audit Logs**: Must include:
  - Timestamp
  - Field type (e.g., `ssn`, `email`)
  - Original value (for audit trail only)
  - Hash result
  - Source IP, user ID, request ID
- **Retention**: 90 days → automated purge.
- **Encryption**: TLS 1.3 enforced at all boundaries.
- **Authentication**: OAuth 2.0 + JWT with scope-based access control.

> ⚠️ **User Preference**: Any deviation from explicit SHA-256 usage will be treated as non-compliance — **no ambiguity allowed**.
